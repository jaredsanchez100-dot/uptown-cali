# Product photos go here

Drop your image files in this folder, then point at them from `../data.js`:

```js
image: "images/built-different-tee-front.jpg",
gallery: ["images/built-different-tee-back.jpg"],
```

**Product shots** — crop 4:5 (about 1200 × 1500 px).
**Lookbook shots** — crop 3:4 (about 1200 × 1600 px).

Keep each file under ~300KB. Squoosh.app or TinyPNG will shrink them without
visible quality loss, and a fast-loading store sells more than a slow one.
